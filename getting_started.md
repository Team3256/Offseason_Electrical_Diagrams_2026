Grayhaven Nerve uses Node.js and Node Package Manager. Find instructions to install both [here](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)

Then install the Grayhaven packages
```npm install @grayhaven/nerve @grayhaven/nerve-connectors @grayhaven/nerve-cli @grayhaven/nerve-compiler @grayhaven/nerve-rules @grayhaven/nerve-exporters @grayhaven/nerve-eval @grayhaven/nerve-connectors @grayhaven/nerve-platform```

In the future if you wanted to create a new Nerve project, use the following command:
```npx nerve init .```

Compile, validate, and render
